# Experiment state snapshot (2026-11-11)

These are lightweight control files copied from `~/hpcResearch/experiment_outputs/{socket_batch2,seed_batch,retune_probe,capacity_probe}`.
The full outputs (~12 GB: model checkpoints `*.pt`, per-fold predictions, logs) are **not** in git.

## What is here
- `*/selection.json`: the hyperparameters and epochs selected by each pipeline run, i.e. the blind/aware
  recipes that later stages build on.
- `*/requested_run_config.json`: the exact config each run was launched with.
- `*/selected_epochs.json`: retune/capacity probe budget selections.
- `*/jobs*.tsv`: the job lists for the runners (`seed_batch_run.py`, `retune_probe_run.py`). The argv uses absolute
  `/home/akhil/hpcResearch/...` paths.
- `*/done.tsv`: completed jobs (name, rc, seconds, start, end).
- `*/configs/` and `socket_batch2/epochmatch_configs/`: generated run configs.

## Resuming on another machine
1. Use the same layout: `~/hpcResearch/repos/coScheduling` (branch `dane`), `~/hpcResearch/repos/Dissertation`, and a
   venv at `~/hpcResearch/python_venvs/ml_analysis`.
   - Python 3.14. Install with `pip install -r scripts/dissertation_figs/requirements_ml_analysis.txt`.
   - The torch wheel is the cu132 build; a CPU wheel works too, since all runs were CPU-only.
   - Scripts hard-code these paths, and `common.py` sets `FIG_DIR` to the Dissertation repo.
2. **To continue or re-score existing runs**, copy the full outputs. Excluding `*.pt` cuts the size a lot; scoring
   only needs the CSV/JSON files:
   `rsync -a --exclude='*.pt' oldhost:hpcResearch/experiment_outputs/ ~/hpcResearch/experiment_outputs/`
3. **To start fresh from the recipes only**, restore this snapshot to its original location:
   `rsync -a scripts/dissertation_figs/experiment_state/ ~/hpcResearch/experiment_outputs/`
   The build scripts (`seed_batch_build.py`, `retune_probe_build.py`, `socket_batch2_epochmatch.py`) read
   `selection.json` and `requested_run_config.json` from there. `socket_batch2/d1_code/` is regenerated by
   `socket_batch2_diag.py`.
4. The runners skip jobs whose `run_report.json` says complete. Without the full outputs, every job reruns. Use
   `nice -n 19`; the runners pin BLAS to 1 thread per worker.

The training data needs no copying. The model inputs are committed in the `notebooks/utils/*_socketAware/data*/`
snapshots and `processed_data/`. The socket-pinned raw logs (`run_data/`, gitignored) are only needed to re-parse;
their parsed output is in `output/socket_pinned_*runs.csv`.

Pipeline notes and pitfalls are in `.claude/skills/coscheduling-data-analyzer/references/findings.md` §§6–9.
